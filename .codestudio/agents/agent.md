# Codestudio Agents

This folder contains agent definitions and documentation for the Codestudio AI agents used in this project.

## Overview

Agents are modular AI assistants that can be invoked to perform specific tasks within the workspace. Each agent has a defined role, set of responsibilities, and tool access.

## Available Agents

| Agent Name | Description |
|------------|-------------|
| Code Studio | Expert AI programming assistant for software engineering tasks |

## Conventions

- All agent documentation lives under `.codestudio/agents/`
- One Markdown file per agent, named after the agent (e.g. `agent.md`)
- Keep documentation focused on role, capabilities, and usage notes

## Adding a New Agent

1. Create a new `*.md` file in this folder
2. Document the agent's role, responsibilities, and tool access
3. Update the table above with the new agent name and description
